# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

## Reporting Vulnerabilities

If you discover a security issue with any linked resource:

1. **Do NOT** create a public GitHub issue
2. Contact the resource maintainer directly
3. Follow responsible disclosure practices

## Broken or Malicious Links

If you find a broken link or suspect a resource has been compromised:

1. Open a GitHub issue with the label `broken-link` or `security`
2. Provide the resource name and URL
3. We will investigate and update/remove as needed

## Disclaimer

This repository aggregates third-party resources. We do not control external content and are not responsible for:
- Security of linked websites
- Accuracy of external information
- Changes to external resources

Always verify resources before use in production environments.
